# Responses

Each file holds the code returned by one model for one prompt, ready to be
dropped into a code cell (no markdown fences, no surrounding prose).

Naming: `<scenario>_<model_id>.py`, where `scenario` and `model_id` come from
`config.toml`.

These files are generated by `fetch_responses.py`:

    pixi run --environment intro-ia python Scripts/llm_notebook/fetch_responses.py

You can also write one by hand if you want to drop in a specific model's
response without calling the API.
